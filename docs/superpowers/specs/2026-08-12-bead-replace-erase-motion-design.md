# 3D 拼豆换色与擦除动效设计

## 目标

在 3D 编辑模式中，让已有豆子的换色和擦除获得与新豆放置一致的即时视觉反馈，同时保持浏览器端快速预览、精确压合几何、相机和豆板的现有语义不变。

## 已确认动效

### 换色

- 当一个有色格被改为另一种颜色时，旧豆立即向上提起并缩小退场。
- 新颜色豆与旧豆退场同时开始，复用现有 370 ms 放置、下落和轻微回弹动画。
- 两段动画并行，避免连续涂色因串行动画而显得迟缓。
- 同一格在动画尚未结束时再次换色，只保留最新一次操作；旧的退场动画不会堆叠。

### 擦除

- 当有色格变为空格时，正式快速层立即隐藏该豆，保证编辑结果立刻正确。
- 旧豆以独立退场影像从当前可见姿态向上提起并缩小，在约 220 ms 后消失。
- 若被擦除的豆仍处于放置动画中，退场从当前动画姿态开始，不跳回最终位置。

### 无障碍与降级

- 开启 `prefers-reduced-motion` 时，换色和擦除立即完成，不播放退场或重新放置动画。
- WebGL 不可用、项目超过 3D 安全上限或上下文丢失时，继续使用现有 2D 降级，不增加新的失败路径。

## 实现边界

- 所有动效都运行在用户浏览器中的现有 Three.js 控制器内，不新增后端接口、项目字段或持久化数据。
- 快速预览层保留当前固定 `cellIndex` 槽位的主 `InstancedMesh`，并增加一个同容量、常驻的退场 `InstancedMesh`。
- 主层负责最新项目状态；退场层只保存换色或擦除前的颜色和当前姿态。两层复用同一份低模豆子几何与物理材质参数。
- 每帧只更新活动槽位的矩阵和实例颜色；不会为每次换色或擦除创建 Mesh、Geometry、Material 或 Worker。
- 精确压合表面继续由现有浏览器 Worker 生成。只有当前修订号的精确结果可以接管画面，并且会等待放置和退场动画全部结束。
- 相机、OrbitControls、豆板、定位柱和拾取平面均不重建或重置。

## 时序与状态

- 新增：沿用现有 370 ms 放置动画。
- 换色旧豆退场：220 ms，向上移动并缩小至不可见。
- 擦除旧豆退场：220 ms，使用相同退场曲线。
- 连续编辑时，每个格独立计时；同一格最新操作覆盖旧操作，不形成无限动画队列。
- `hasActiveAnimations()` 同时统计放置和退场动画，确保精确表面不会提前切断动画。

## 测试与验收

- 严格 TDD：先增加换色、擦除、动画中反向操作、连续多格、减少动态效果和资源释放的失败测试。
- 真实 Three.js 场景断言主层与退场层均为常驻实例网格，换色时旧色退场且新色落下，擦除时主槽立即隐藏而旧豆仍完成退场。
- 控制器测试锁定精确表面只在当前修订号且两类动画结束后接管，相机和豆板引用保持不变。
- 性能门禁继续覆盖 3,532 豆和 16,384 槽位；连续操作不得每帧分配大对象或触发 Worker/几何重建。
- 最终在真实 Chrome 中验证顶视与旋转视角下的连续换色、连续擦除、撤销和精确模型收敛。

## 非目标

- 不改变 2D 动效、工具语义、撤销历史或精确 SVG/打印几何。
- 不增加用户可调动画参数。
- 不实现粒子、弹簧过冲或声音效果。
