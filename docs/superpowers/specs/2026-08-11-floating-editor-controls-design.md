# 拼豆工作台悬浮控件设计

## 目标

把编辑步骤改成以画布为中心的工作区：画布占满可用区域，常用编辑控件悬浮在左侧，参数与制造交接控件悬浮在右侧，视图切换悬浮在顶部。视觉上对齐 Lumina 图像转换页，同时吸收 pindou520 的“工具围绕画布”思路，不引入主仓库完整的可拖拽 Widget 系统。

## 已确认范围

- 桌面端使用固定左右悬浮坞；两侧面板可独立折叠，但首版不能拖拽、换边或重排。
- 现有独立标题卡和双栏文档流不再占据编辑区；项目标题、网格尺寸、返回校准和新建操作并入左坞顶部。
- 顶部中央显示“原图 / 识别矩阵 / 压合预览 / 3D 预览”。
- 左侧为高频编辑：项目尺寸与返回校准/新建、原色/打印色切换、画笔/橡皮/区域擦除/吸管/填充、撤销/重做、色板、自定义色、待复核导航和网格开关。
- 右侧为低频参数与输出：色库状态和映射、压合程度与预设、不规则度、单豆节距、成品尺寸与厚度、交给 Lumina 转换。
- 选中格放大镜继续悬浮在画布下方区域，并通过右坞占用宽度自动避让。
- 不改变识别、编辑 Reducer、SVG/3D 渲染、色库映射、保存或 Lumina handoff 的业务语义。

## 桌面布局

`BeadEditorStep` 继续作为唯一状态协调层。编辑区以 iframe 当前可见高度为基础建立局部定位工作区：中央画布是底层，悬浮控件是同级覆盖层，不能放进带滚动的画布容器内。

- 画布层：填满工作区，可独立缩放、滚动或旋转。
- 顶部视图栏：居中悬浮，避让左右坞；保持四个现有视图的状态与禁用规则。
- 左坞：宽度约 `248–320px`，内部独立纵向滚动。
- 右坞：宽度约 `280–350px`，内部独立纵向滚动。
- 两侧与边缘间距 `12px`，面板间距 `8px`；标题栏高度约 `40px`。
- 面板使用现有主题变量、细边框和轻量半透明表面，不增加高成本毛玻璃滤镜或新的视觉依赖。
- 覆盖层根节点使用 `pointer-events: none`，实际按钮、表单和面板恢复 `pointer-events: auto`，避免点击穿透到矩阵画布。

折叠状态只属于当前编辑会话，不写入工程文件或 SDK 存储。桌面默认两侧展开；折叠后中央画布立即获得更多可视宽度。

## 窄屏布局

当编辑区宽度不大于 `900px` 时，左右坞改成单个底部抽屉：

- 保留顶部视图栏。
- 底部显示“编辑”和“参数”两个入口，同一时间最多打开一个抽屉。
- 抽屉最大高度不超过视口的 `55%`，内容内部滚动，色板横向滚动。
- `Esc` 关闭抽屉并把焦点还给触发按钮；按钮暴露 `aria-expanded` 和 `aria-controls`。
- 抽屉关闭时画布不被透明层拦截；放大镜改为画布内的小卡片或普通文档流，不能与抽屉重叠。
- 当编辑区宽度不大于 `520px` 时，两个入口等宽占满底部，抽屉横向铺满工作区，并收紧内部间距而不缩小触控目标。

## 组件边界

- `BeadEditorStep`：保留所有业务状态、派生数据、画布选择和回调编排。
- `BeadEditorFloatingControls`：受控展示顶部视图栏、左侧高频编辑控件及窄屏入口；不保存业务状态。
- `BeadEditorInspector`：受控展示右侧参数、色库映射、尺寸信息和 handoff；不直接访问 SDK 或 Store。
- 现有 `BeadMatrixCanvas`、`BeadFusionPreview`、`BeadThreePreview`、`BeadSourceCanvas` 与 Reducer 接口保持不变。

首轮不继续拆分色库映射行、Slider 或 CanvasStage，避免为布局改造扩大业务接口。

## 状态与错误处理

- 展开、折叠或切换抽屉不能重置当前视图、工具、色板、网格或撤销历史。
- 图纸原色/打印色仅改变矩阵、压合和 3D 的显示，不能污染源色工程或 handoff。
- 工具与色板点击必须停止事件穿透；只有画笔和橡皮允许矩阵拖动，其他工具仍是单击语义。
- 色库不可用、映射过期、3D 超限及 Worker/WebGL 降级继续使用现有提示和回退路径。
- 本次不增加网络请求、持久化格式或模块权限。

## 验收与测试

自动化回归必须覆盖：

1. 现有工具、视图、撤销重做、色板、待复核、压合预设、区域擦除、handoff 与过期映射行为全部保留。
2. 点击悬浮控件不会触发矩阵编辑。
3. 折叠面板或切换移动端抽屉后，视图、工具和网格状态保持不变。
4. 原色/打印色切换只改变预览，handoff 仍使用源色工程。
5. 折叠按钮和移动端抽屉具备正确的 `aria-expanded`、`aria-controls`、Esc 与焦点返回行为。
6. CSS 契约锁定工作区定位、画布滚动、覆盖层指针策略、坞宽避让和窄屏抽屉规则。
7. 保留矩阵边界、拖动语义、3D Worker 生命周期与 4096 颗豆安全降级测试。

人工验收使用当前复杂图纸，分别检查浅色/深色主题及 `1280px+`、`900px`、`520px` 三档：画布应始终是视觉主体，左右面板不遮挡关键内容，3D 旋转与矩阵编辑不受影响。

## 明确不做

- 不照搬 Lumina 主仓库的 Widget Store、拖拽排序、布局持久化或转换业务组件。
- 不加入 pindou520 的局部熨烫玩法、固定色轮或 WASD 视角逻辑。
- 不改识别算法、压合几何、3D 模型、工程格式或 Lumina SDK 合同。
