# Lumina Fuse Bead Studio

Lumina Studio 的官方拼豆工作台模块。它识别清晰图纸或截图，允许逐格校正，并将熨烫融合后的源色图像交给 Lumina 原有的叠色打印流程。

The official Fuse Bead Studio module for Lumina Studio. It recognizes clear pattern charts, supports cell-level correction, and hands the fused source-color image to Lumina's existing layered-color conversion flow.
